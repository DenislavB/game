# Emberfall

A single-player, low-poly RPG prototype built in **Godot 4** that recreates the *feel* of a classic 2004-era MMORPG: slow deliberate combat, a grindy 1–60 leveling curve, large sparse hand-laid zones, quest hubs with `!` and `?` markers, talents, trainers, vendors, loot, and downtime spent eating and drinking.

Everything is procedural or data-driven — there are no binary assets in the repo. The whole world (terrain, trees, buildings, characters, animations) is generated in code with flat-shaded low-poly primitives.

## Running it

1. Install [Godot 4.3+](https://godotengine.org/download) (the standard editor, no extras needed).
2. Open this folder with the Godot editor (`project.godot`).
3. Press **Play** (F5).

First zone load takes a few seconds — the terrain mesh is generated at runtime.

> Exporting a build: add `*.json` to *Export > Resources > Filters to export non-resource files* so the `data/` folder is packed.

| Input | Action |
|---|---|
| W / S | Move forward / backpedal (slow, as it should be) |

| Right-click | Interact / loot / attack |

| Space | Jump |
| Esc | Cancel cast → clear target → close windows |

## What's implemented

- **2 races** (Orc, Human — each with a racial ability) and **3 classes**:
  - **Warrior** — rage generated by dealing/taking damage, Charge, Rend, Execute…
  - **Mage** — mana with the 5-second rule, cast times, Polymorph, Blink, conjured food/water
  - **Hunter** — ranged auto-shot with a minimum range, stings, a wolf pet with real threat
- **Classic combat math**: attack tables (miss/dodge/crit by level difference), armor mitigation, spell resists, weapon speeds, GCD 1.5s.
- **60 levels** with a grindy XP curve, gray-mob cutoffs, full heal on ding.
- **Talents**: 3 trees per class, 1 point/level from 10, tier gating, 31-point capstones that grant abilities (Mortal Strike, Pyroblast, Ice Barrier, Bestial Wrath…).
- **Trainers** teach new abilities for copper at level milestones — visiting your trainer matters.
- **3 zones** (Guild-Wars-2-style separate maps with travel points):
  - **Sunscorch Mesa** (Orc start, 1–10) — red rock, cacti, harpy plateau, an elite matriarch
  - **Greenhollow Vale** (Human start, 1–10) — pine forest, bandit camps, an elite bandit captain
  - **The Dustplains** (contested, 10–20) — a huge sparse savanna with a central caravan hub, centaur-like clans, and two elite group-quest bosses
  - 7 more zones (to level 60) are designed as stubs in `data/zone_stubs.json`.
- **~40 quests**: kill, collect (drop-chance items), delivery/breadcrumb, exploration, multi-point patrols, elite "bring friends" quests.
- **Mob AI**: proximity aggro scaled by level difference, chase, **leash + evade with full heal**, threat tables (your pet can tank), casters, timed respawns, wandering.
- **Loot**: corpse looting, junk/trash economy, quality colors, loot pools, rare drops.
- **Items & vendors**: equipment slots with stats, buy/sell, food/water/potions.
- **Downtime**: sit to eat and drink — health and mana regen are slow on purpose.
- **Professions**: mining, herbalism (world nodes) and skinning (corpses), skill 1–300.
- **HUD**: unit frames, action bar with cooldown sweeps, cast bar, XP bar, buff row, quest tracker, floating combat text, combat log, zone-name splashes, death & release flow.
- **Save/load**: autosaves every 30s and on zone travel / quit (`user://emberfall_save.json`).

## Project layout

```
data/                  All game content as engine-agnostic JSON
  classes.json         Base stats, per-level growth, starter gear
  abilities.json       Every ability (costs, ranges, effects) — interpreted, not hardcoded
  talents.json         3 trees per class
  items.json           Weapons, armor, consumables, junk, quest items
  mobs.json            Mob templates (model shape/color, AI flags, loot table)
  loot_tables.json     Drop chances and pools
  zones/*.json         Full zone layouts: terrain params, palette, camps, roads,
                       NPCs, spawns, gather nodes, graveyard, exits
  quests/*.json        Quests per zone
scripts/
  autoload/            DB (data loader), Events (signal bus), Game (character state, save)
  core/formulas.gd     ALL tuning constants and combat/XP math in one place
  world/               Terrain gen, procedural props/buildings, character models, zone builder
  actors/              Unit base, Player, Mob, Pet, NPC, gather nodes
  ui/                  HUD + all windows, built in code
  screens/menus.gd     Main menu + character creation
scenes/Main.tscn       The only scene — everything else is built in code
```

## Adding content

- **A new quest**: add an entry to `data/quests/<zone>.json` (giver/turnin reference NPC ids from the zone file). That's it — markers, tracker, dialog and rewards are automatic.
- **A new item / mob / ability**: add a JSON entry; loot tables and spawns reference ids.
- **A new zone**: copy a `data/zones/*.json` file, change the seed/palette/layout, add a quests file, and link it via `exits`/`entrances`. The zone builder does the rest.
- **Tuning the feel**: nearly every number (XP curve, rage gen, regen ticks, aggro radii, mob HP/damage) lives in `scripts/core/formulas.gd`.

## Known simplifications (roadmap)

- No armor-class restrictions (cloth/leather/mail/plate) and no ability ranks yet — ability damage scales with level instead.
- Hunter pet is a fixed wolf via *Call Pet* (no taming/feeding/happiness yet).
- No corpse runs — death respawns you at the zone graveyard at half health.
- No swimming, mounts, dungeons, or audio yet.
- Action bar holds 10 abilities; manage it from the Character window (right-click an ability to place it).
- Zones 20–60 are design stubs (`data/zone_stubs.json`).
